# Sweety frontend

The React/Vite client for Sweety. For database setup and full-stack instructions, see the [project README](../README.md).

## Run locally

From this directory, install dependencies and start the development server:

```powershell
npm install
npm run dev
```

Vite serves the client and proxies `/api/*` requests to the backend at `http://localhost:5001`.

## Checks

```powershell
npm run lint
npm run build
```
